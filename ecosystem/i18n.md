# i18n

**cbi18n** adds internationalization to ColdBox: resource bundles, locale-aware messages, and per-request locale detection.

```bash
box install cbi18n
```

📖 **Full documentation:** [ForgeBox](https://forgebox.io/view/cbi18n) · [GitHub](https://github.com/coldbox-modules/cbox-i18n)

## Quick Example

Store messages in resource bundles (Java `.properties` style), resolve them anywhere:

```properties
# includes/i18n/main_en.properties
welcome = Welcome back, {name}!
```

```properties
# includes/i18n/main_es.properties
welcome = ¡Bienvenido de nuevo, {name}!
```

```javascript
// In a handler or view
property name="i18n" inject="i18n@cbi18n";

message = i18n.getResource(
    resource : "welcome@main",
    values   : [ user.getName() ]
)
```

The module can detect the user's locale from the request (`Accept-Language`, URL, or cookie) and store it in the request context, so every `getResource()` call resolves in the right language automatically.

## When to Use It

- Multi-language applications
- Locale-aware validation messages (pairs with [cbvalidation](validation.md))
- Centralizing user-facing strings out of views
